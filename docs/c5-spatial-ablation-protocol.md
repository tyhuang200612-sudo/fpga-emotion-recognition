# C5 结构消融：TinyCNN GAP 1×1 对比 GAP 2×2

启动时间：2026-10-17。正式 Kaggle GPU 工作流：[GitHub Actions #39004573026](https://github.com/tyhuang200612-sudo/fpga-emotion-recognition/actions/runs/39004573026)。私有 Kaggle notebook：<https://www.kaggle.com/code/tyhuanga/fpga-c5-gap1-vs-gap2-ablation>。

## 设计动机
- 同一组用户明确标注的 **19 张真实手机悲伤图** 上，C2-C FP32 学生认出0张、C3训练专用强教师认出18张；图像连续采集，**样本之间非独立**，所以只能作为定位线索，不能当总体准确率。用户纠正其余46张标注未及时切换，全部按未知标签处理。
- C2-C / C3 / C4 学生蒸馏或损失组合没有稳定提高 FER2013 Macro-F1。此次 **不训练新教师、不调整分类阈值、不使用手机诊断图训练或选择模型**；只检验卷积后空间信息在末端池化中的保留是否有贡献。
- 结构假设：1×1 GAP 压缩最后 64×12×12 特征图到64维；2×2 自适应平均池化保留4个空间象限、得到256维，再由FC输出3类。假设有合理性但**未证实**能显著改善悲伤识别。

## 两组结构完全相同的卷积主干
| 资源（理论结构估计） | GAP1 控制组 | GAP2 新实验 |
|---|---:|---:|
| 输入 | 灰度48×48 | 灰度48×48 |
| 四层卷积通道 | 16/32/64/64 | 16/32/64/64 |
| 末端池化 | 1×1 | 2×2 |
| FC权重数量 | 64×3 = 192 | 256×3 = 768 |
| Conv+FC权重（不计BN与bias） | 60,240 | 60,816 |
| 新增权重 | — | **576** |
| 主卷积MAC/帧 | 相同 | 相同 |
| 末端FC MAC/帧 | 192 | 768 |
| 池化后每帧激活个数 | 64 | 256 |

> 这里的资源数只是 FP32 网络构造下的理论计数，**不是 FPGA 实测**。增加的池化激活缓冲、量化、BN融合、ROM组织、BRAM/寄存器、RTL和时序需要后续独立检验；不可声称已完成安路板部署。

## 控制变量设计（重点）
1. 两组都从同一份**真实冻结 C2026 checkpoint**加载卷积及BN权重；GAP1 复制原末端FC；GAP2 将原 FC 对每个象限的权重各复制一份、同时除以4，因此在训练开始前 GAP2 输出与 GAP1 基本相同（CPU回归检查要求误差<1e-5）。
2. 都用冻结的 FER2013 cleaned train/val：13,571 训练、2,979 验证，按输入哈希防交叉泄漏。用户手机私有图、FER2013 官方独立TEST 不参与调参。
3. 两组各用随机种子 **20261021、20261022**，相同增强、AdamW、batch 64、初始学习率2e-4、epoch最多25、patience 7。每轮仅按验证 Macro-F1 保留该模型最佳 checkpoint。
4. 指标包括 Macro-F1、准确率、中性与悲伤召回、**中性→悲伤加悲伤→中性**的双向混淆次数；两种随机种子分别记录，不能仅报最好一次。
5. 保留历史 C2-C 同一 FER VAL 参考 F1=0.7515864、双向混淆408。预设资格：GAP2两种子各提升 Macro-F1 ≥0.005、双向混淆至少少10次、两类召回相对C2-C分别不得低于0.02；同时 GAP2相对同期GAP1平均 Macro-F1至少提高0.005。未达标时保留原版模型。

## 阶段划分
- **C5 初步只进行 FER 验证集的结构消融**：完成后查看是否确有稳定泛化提升。不能因多轮反复使用同一验证集择优就认定真实效果。
- **后续独立测试**：必须先取得自愿标注、按人及拍摄会话隔离的新手机评测数据。19张连续图不能既当优化信号又当最终验收指标。
- **如果 C5 有希望**：再做一次轻量蒸馏对照，INT8 的 PyTorch/ONNX/RTL 可比精度验证、安路实际面积/时序测试。只有通过这些关口才考虑替换既有 C/C2-C。

## 可复现代码及交接
- `src/model_c5.py`：2×2 结构、从原C权重精确初始化和资源估算。
- `tools/train_c5.py`：两组×两种子训练、验证、混淆矩阵、自动保护原模型。
- `tools/build_kaggle_c5.py`：私有 GPU Kaggle Notebook生成；不会在本地跑模型。
- `tests/test_c5_spatial.py`：logit parity、梯度、额外576权重、Notebook语法与 TEST 隔离测试。
- `.github/workflows/kaggle-c5-spatial-ablation.yml`：云端编译检查、Kaggle挂载验证、训练日志、权重归档。
- 生成的 GitHub Actions artifact 保留期30天。后续正式交接必须下载、SHA256校验并与 C2/C3/C4 合并归档；不能把归档链接当做永久备份。
