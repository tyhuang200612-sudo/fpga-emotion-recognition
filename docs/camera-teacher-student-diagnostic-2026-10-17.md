## 关键对照方法

- 输入：用户手动导出的手机诊断图片（PNG，48×48 灰度，原端归一化至 [0,1]），**所有模型逐张使用同一张输入图片**。
- 65 张图，用户明确确认其中手动标注的 **19 张悲伤标签可靠**；另外 46 张原标签未及时切换（中性/开心混合），**所有46张必须视为标签未知，不允许统计准确率或召回率，也不能自动改标签**。
- 19 张悲伤图为连续短时间拍摄，可能包含高度相似甚至重复帧，因此以下 18/19、0/19 只能说明当前这组场景，不代表独立总体准确率，更不能据此选择最终部署模型。
- 65 张使用同一 1.36× 裁剪比例，因此 **仍没有不同裁剪比例的对照**。
- C2-C 权重：C2 GPU 真实归档 Run [38995638992](https://github.com/tyhuang200612-sudo/fpga-emotion-recognition/actions/runs/38995638992) 的 `C_distilled/best.pt` seed 2026 epoch 12；教师：C3 GPU 归档 Run [38999204120](https://github.com/tyhuang200612-sudo/fpga-emotion-recognition/actions/runs/38999204120) 的 `pretrained_teacher/best.pt`，冻结 SHA256 `ce455ee8060e19d87be16d50926c881b672d172c2ea260bf0ad5e01572861b0c`。
- 离线推理：PyTorch CPU FP32；教师沿用训练定义 ResNet18，128×128 双线性上采样，三通道重复与 ImageNet mean/std；学生采用原 16/32/64/64 TinyCNNC。手机保存的是 PNG，出现8bit灰度回写量化，和保存在 JSON 的手机内存 FP32 概率存在轻微数值差异。C2-C 模型重新推理和手机记录相比，65图概率 **每样本平均三类绝对误差和0.00882，最大单类绝对误差0.02244**，各样本预测类别一致。没有发现能解释19次误判的 ONNX 或 APK 模型替换错误。

## 重要注意

1. **不能声称教师在手机上总体准确率95%**：19张近似连续帧不能代表独立样本，另46张真实标签不明；这部分教师还预测了不少“悲伤”，仍需独立正确标签确认是否过度预测。
2. 未对冻结官方 TEST 重新做模型选择；这些真人手机样本也不能又用于C5训练、又作为C5独立测试。
3. 下一阶段应采用两个互不重叠的手机来源样本集：自愿参与、明确正确标签，按人/场景/拍摄时段划分，一个用于诊断/适配，另一个封存做独立测试。
4. **优先做受 FPGA 资源约束的结构消融**：TinyCNN-C 现用 Global Average Pooling，可能抹掉眼睛/眉毛/嘴巴的局部位置信息。比较轻量空间池化或空间特征头；要求提供参数、MAC、BRAM、INT8 量化开销，禁止虚构板端结果。
5. 先用训练数据与不含真人手机测试的独立 FER VAL 比较各结构，然后用封存的手机测试集做一次综合评估；保留旧 FPGA C/C2-C 权重不覆盖。
6. 改阈值只会移动中性/悲伤界限，可能牺牲中性精度，不能解决模型特征不足；不可直接把阈值微调称为模型质量提升。
